# Task 4 · 双平台 Chrome 采集插件

提交 `f132386`，范围仅 `extensions/chrome/`。

- Chrome MV3 弹窗支持服务器、直播会话 ID、采集密钥和平台配置。通过一个空批次校验本场 token，再从显式启动的标签页读取互动。activeTab 读取当前直播页，服务器权限按需申请。
- 后台校验运行标识、标签页、顶层 frame、document ID、平台和房间。启动、停止及状态写入按序执行，停止时中止当前 HTTP 请求并移除会话密钥。
- 抖音和小红书各有独立 DOM 解析器。历史 DOM 作为启动基线，未知结构及缺失字段跳过。礼物需要独立通知标记和明确可见的礼物名称、数量，聊天正文中的送礼文案保留为正常评论。昵称与正文以纯数据上报。
- 观察器显式启停。队列上限 100，单批 20，最近 DOM 消息 ID 上限 1000。暂时网络失败使用原 ID 重试，超时或拥堵移出的数量在弹窗显示。
