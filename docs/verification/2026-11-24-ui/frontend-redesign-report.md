# LingCast 管理端视觉改版

采用已选定的钴蓝编辑室设计，入口、工作台、人物与素材、话术库和服务设置均已更新。桌面使用导航侧栏、左侧预览和口播区、右侧开播准备。窄屏使用顶部导航和单列布局。事件采集与外部转推使用原生可展开面板，转推异常状态保留在折叠标题中。

人物形象缩略图与未开播预览读取所选图片的真实素材地址，切换后忽略旧请求结果。直播视频维持原有 FLV 播放与卸载逻辑。开播前后均显示对应状态，已有场次使用服务端人物、形象、平台。设置页分别展示处理服务就绪状态和模型连接结果。后端契约未变。

前端使用 Tailwind CSS 4 的 Vite 集成、主题变量、语义化组件和 Lucide 图标。16 个 Vitest 用例通过，涵盖原有 15 个行为用例和新增的服务检查结果展示用例。转推用例经展开面板再操作。TypeScript 与 Vite 生产构建通过。页面分辨率检查由主任务使用本地服务验收；单元测试不覆盖真实 GPU、外部 RTMP 或浏览器插件。

## 复核修正

开播失败、场次错误和普通请求错误共用中文提示组件，保留可展开的服务端详情。运营者可以从开播失败处直接进入服务设置检查连接。390px 导航采用单行“人物素材”，语义按钮名称保持“人物与素材”。选中与未选中导航使用同一响应式文字规则。新增了开播失败到服务检查的行为测试，17 项测试通过，生产构建成功。实际截图由主任务复核。

3. 根据运营者反馈，开播准备的“默认口型底片”提供“上传 / 更换底片”入口。保留当前人物、形象，自动定位到静音待机视频上传和默认底片选择区。缺少人物或形象时显示选择指引。返回直播控制会重新读取形象与默认底片状态。测试验证保留人物和形象、现有底片、上传按钮和键盘焦点。全部 18 项测试及生产构建通过。
