## 90 分钟假时钟

从 0 到 90 分钟逐分钟驱动 Go 调度、SQLite 及本地模型和 Worker HTTP 测试替身，单测不等待实际时间流逝。提交 85 个自主段，覆盖 29 个不同主题；一次主动提供相同候选触发重新生成。第 20 分钟送入 25 条合成评论，第 30–35 分钟暂停后恢复，第 45 分钟遭遇模型输出错误，第 55 分钟收到失败回执，第 60 分钟模拟缺失回执。失败时检查退避期限及提前 tick，失败和缺失回执均未推进已播记忆。第 90 分钟场次仍在直播。测试逐次检查主题储备、互动与已播上下文、在途自主任务和模型并发界限。合成文字只用于验证调度和去重。
