## 实施中确定的默认

1. 将用户的“执行计划，子代理分工执行”视为修正后设计的执行授权。仅在新项目进行可逆的本地开发；不包含生产发布。
2. 新建独立仓库作为隔离空间，没有从旧版创建关联 worktree。改变此选择仅涉及项目目录与仓库组织。
3. 固定接口文档后，按独立目录分工业务、界面和模型执行模块；集成阶段校验接口。代价是需要处理跨模块契约差异，已加入实际 Compose 联调。
4. `/api/live.session` 表示活动场次或 null，另加 `lastSession` 保留最近结束/失败记录。旧 UI 语义不变；如需展示历史状态，可消费附加字段。
5. Worker 将较长原文顺序拆成不超过240个 Unicode 码点的模型请求，优先句末切分，不截断原文。分段语气与衔接仍需真实音色验收。
6. 插件确认协议增加 `processedIds` / `retryIds`。Go 保存 pending/done，插件仅移除明确完成项。第一版新插件要求该确认协议，不能直接接旧版仅返回数量的接口。
7. Worker 使用 Python3.12；两种 GPU 模型各自使用与固定上游依赖匹配的 Python3.10 环境和 CUDA 镜像。不能将两个模型依赖直接混装。
8. 第一版持久化模型与底片预处理缓存，不保存可重放的完整生成口播缓存。每段带素材/音色/文本身份；重复固定稿会再次推理，延迟和GPU开销需要实测。
9. 已提交到模型的底片预处理不能假装立即取消。停止后不安装过期场次，准备/退休未结束前保持忙碌；极端情况下须等准备调用完成或超时，再开播。
