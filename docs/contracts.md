# V1 contract
All IDs strings (UUID). JSON camelCase. Go API /api; admin Bearer ADMIN_TOKEN except /healthz. Upload GET /media/{id} supports separate MEDIA_TOKEN query `token`; Go generates absolute URLs using PUBLIC_BASE_URL. Browser admin uses Bearer except media previews. SQLite WAL at DATA_DIR/app.db, filesystem media DATA_DIR/media. Go pure Go sqlite driver modernc.org/sqlite. React+TypeScript Vite management. JSON errors {error:string}; resource create 201, conflicts409, validation400, auth401, unavailable503.

## Admin API
GET/POST /api/avatars; POST {name,persona,voiceId}; GET/PATCH/DELETE /api/avatars/{id}. Persona free-text. avatar {id,name,persona,voiceId}.
GET/POST /api/avatars/{id}/looks; POST {name,imageId}; look {id,avatarId,name,imageId,defaultIdleId}.
PATCH/DELETE /api/looks/{id}; PATCH {name?,imageId?,defaultIdleId?}.
GET/POST /api/looks/{id}/idles; POST {mediaId}; idle {id,lookId,mediaId}.
DELETE /api/idles/{id}.
GET/POST /api/avatars/{id}/scripts; POST {kind,text}; kind host|welcome|gift|like|comment. script {id,avatarId,kind,text}. PATCH/DELETE /api/scripts/{id}.
POST /api/media multipart `file` -> media {id,url,kind,width,height,fps,sha256}; require image or silent video; ffprobe and full ffmpeg decode video, bounded upload 200 MiB. GET /api/media/{id} metadata. Image max 30MiB. Never trust client path/name.
GET /api/live -> {session:Session|null}; POST /api/live {avatarId,lookId,platform} -> {session,collectorToken}; platform douyin|xiaohongshu. Session {id,avatarId,lookId,platform,status,hostEnabled,relayState?,previewUrl,error,createdAt}. POST /api/live/{id}/stop; POST /api/live/{id}/speak {text}; PATCH /api/live/{id}/host {enabled}; PUT /api/live/{id}/relay {enabled,server,streamKey}. GET /api/settings -> safe {timezone,workerUrl,llmUrl,llmModel,configured:{...}} env-backed read-only; POST /api/settings/check tests worker/model connectivity without changing config. POST /api/live/{id}/collector-token rotates token.
POST /api/collector/events Bearer collectorToken {sessionId,platform,events:[{id,kind,nickname,text}]} -> {accepted,serverTime,processedIds:string[],retryIds:string[]}. processedIds contains durably completed/new-or-done-duplicate IDs only; pending duplicate or failed work remains retryIds. Plugin removes only processedIds, retries unresolved stable IDs. kinds comment|enter|gift|like. Token per session, stored hashed, rejected after stop, platform mismatch400.

## Go -> Worker REST
Bearer WORKER_TOKEN. GET /healthz returns {ready:bool,error?:string}; GET /status -> {sessionId,status,previewUrl,error,relayState}. POST /sessions body {sessionId,avatarId,lookId,voiceId,imageUrl,idles:[{id,url,sha256}],defaultIdleId,platform}; idles.id is idle record id; start must validate default material and rendering preparation before success. Response {previewUrl}. POST /sessions/{id}/stop; POST /sessions/{id}/tasks {id,kind,text,createdAt,expiresAt}; kinds manual|gift|like|comment|welcome|host, priority that order. PUT /sessions/{id}/relay {enabled,server,streamKey}. All prior session routes reject stale sessionId. Worker tasks bounded 100, expire120s, dedup event/task id for session; status unhealthy on dead ffmpeg. Go sends host only when host enabled and Worker /status reports idle task queue; repeated host throttled by last task completion (Worker status {queueDepth,speaking}). No automatic external RTMP. Worker serves /preview/{sessionId}.flv as authenticated proxy of SRS (Go proxy /api/live/{id}/preview?token=ADMIN_TOKEN for browser); never expose model or stream secrets to UI.

## Models
Reuse resident CosyVoice /tts NDJSON and MuseTalk /render NDJSON from old project. Adapt generic look registration/preparation and per-voice reference config, no reserved avatar IDs. Worker consumes render's paired audio/JPEG events which currently calls CosyVoice internally; configurable TTS URL on renderer. Maintain PCM/JPEG clock verification and model/voice/text/material fingerprinting. Real model weights/sources external mounted volumes, version-lock build inputs; no dummy service reported as real ready. Model manifest {profiles:{voiceId:{promptText,promptAudio}},looks:{lookId:{basePath,sha256}}} can be generated during preparation. Expose documented real prepare endpoint to accept downloaded default idle and bind lookId/hash. Exact endpoint is worker-owned and documented by its implementer. Network auth every model request. GET model health/ready protected. Model downloads require explicit operator action, never silently clone main.

## Scheduling, relay and look status
Once a task starts, the Worker drains each spoken segment (up to 240 characters) and selects the highest-priority waiting work. Its exact remainder retains the original FIFO position and reserved queue slot. The 120-second expiry applies until the first segment starts.

Worker relayState is disabled, running (the FFmpeg child is alive), or failed (launch failed or the requested child exited). GET /api/live reads only the matching session's process state and returns unknown if unavailable. The studio shows launching after accepting an enable request until the next status read. Process liveness does not confirm platform ingest. Disable clears the requested relay without stopping preview.

MuseTalk loads shared models at startup. Preparing a look verifies the supplied base SHA and activates one look/hash in memory. Versioned materials and prepared artifacts remain on disk. Render requires the selected binding, matching base file SHA and resident profile.
