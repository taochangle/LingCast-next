# V1 contract
All IDs strings (UUID). JSON camelCase. Go API /api; admin Bearer ADMIN_TOKEN except /healthz. Upload GET /media/{id} supports separate MEDIA_TOKEN query `token`; Go generates browser URLs using PUBLIC_BASE_URL. Worker start media URLs use optional WORKER_MEDIA_BASE_URL, falling back to PUBLIC_BASE_URL; same-Compose deployments can use http://app:8080. Browser admin uses Bearer except media previews. SQLite WAL at DATA_DIR/app.db, filesystem media DATA_DIR/media. Go pure Go sqlite driver modernc.org/sqlite. React+TypeScript Vite management. JSON errors {error:string}; resource create 201, conflicts409, validation400, auth401, unavailable503.

## Admin API
GET/POST /api/avatars; POST {name,persona,voiceId,interests?,hostMode?}; GET/PATCH/DELETE /api/avatars/{id}. Persona accepts up to 4096 Unicode characters on write. Avatars also expose hostMode, interests and revision.
GET/POST /api/avatars/{id}/looks; POST {name,imageId}; look {id,avatarId,name,imageId,defaultIdleId}.
PATCH/DELETE /api/looks/{id}; PATCH {name?,imageId?,defaultIdleId?}.
GET/POST /api/looks/{id}/idles; POST {mediaId}; idle {id,lookId,mediaId}.
DELETE /api/idles/{id}.
GET/POST /api/avatars/{id}/scripts; POST {kind,text}; kind host|welcome|gift|like|comment. script {id,avatarId,kind,text}. PATCH/DELETE /api/scripts/{id}.
POST /api/media multipart `file` -> media {id,url,kind,width,height,fps,sha256}; require image or silent video; ffprobe validates source and FFmpeg converts video to silent H.264 MP4 at 25 fps (odd dimensions padded to even), bounded upload and converted output 200 MiB. Stored metadata/SHA256 describe the converted file. GET /api/media/{id} metadata. Image max 30MiB. Never trust client path/name.
GET /api/live -> {session:Session|null}; POST /api/live {avatarId,lookId,platform,hostMode?} -> {session,collectorToken}; platform douyin|xiaohongshu. Session {id,avatarId,lookId,platform,status,hostMode,hostEnabled,relayState?,previewUrl,error,createdAt}. POST /api/live/{id}/stop; POST /api/live/{id}/speak {text}; PATCH /api/live/{id}/host {enabled}; PUT /api/live/{id}/relay {enabled,server,streamKey}. GET /api/settings -> safe {timezone,workerUrl,llmUrl,llmModel,configured:{...}} env-backed read-only; POST /api/settings/check tests worker/model connectivity without changing config. POST /api/live/{id}/collector-token rotates token.
POST /api/collector/events Bearer collectorToken {sessionId,platform,events:[{id,kind,nickname,text}]} -> {accepted,serverTime,processedIds:string[],retryIds:string[]}. processedIds contains durably completed/new-or-done-duplicate IDs only; pending duplicate or failed work remains retryIds. Plugin removes only processedIds, retries unresolved stable IDs. kinds comment|enter|gift|like. Token per session, stored hashed, rejected after stop, platform mismatch400.

## Go -> Worker REST
Bearer WORKER_TOKEN. GET /healthz returns {ready:bool,error?:string}; GET /status -> {sessionId,status,previewUrl,error,relayState}. POST /sessions body {sessionId,avatarId,lookId,voiceId,imageUrl,idles:[{id,url,sha256}],defaultIdleId,platform}; idles.id is idle record id; start must validate default material and rendering preparation before success. Response {previewUrl}. POST /sessions/{id}/stop; POST /sessions/{id}/tasks {id,kind,text,createdAt,expiresAt}; kinds manual|gift|like|comment|welcome|host, priority that order. PUT /sessions/{id}/relay {enabled,server,streamKey}. All prior session routes reject stale sessionId. Worker tasks bounded 100, expire120s, dedup event/task id for session; status unhealthy on dead ffmpeg. Go sends host only when host enabled and Worker /status reports idle task queue; repeated host throttled by last task completion (Worker status {queueDepth,speaking}). No automatic external RTMP. Worker serves /preview/{sessionId}.flv as authenticated proxy of SRS (Go proxy /api/live/{id}/preview?token=ADMIN_TOKEN for browser); never expose model or stream secrets to UI.

## Scheduling, relay and look status
Once a task starts, the Worker drains each spoken segment (up to 240 characters) and selects the highest-priority waiting work. Its exact remainder retains the original FIFO position and reserved queue slot. The 120-second expiry applies until the first segment starts.

Worker relayState is disabled, running (the FFmpeg child is alive), or failed (launch failed or the requested child exited). GET /api/live reads only the matching session's process state and returns unknown if unavailable. The studio shows launching after accepting an enable request until the next status read. A matching Worker reporting error changes the session to error and revokes its collector token, including while hosting is paused. Stop must reconcile the Worker before another session can occupy the slot. Process liveness does not confirm platform ingest. Disable clears the requested relay without stopping preview.

MuseTalk loads shared models at startup. Preparing a look verifies the supplied base SHA and activates one look/hash in memory. Versioned materials and prepared artifacts remain on disk. Render requires the selected binding, matching base file SHA and resident profile.

## Companion host

New avatars default to `companion`. Existing avatars migrate to `fixed`. An optional start-time override selects the mode for that session. Both start paused. Admins may edit persona and interests during the session. The revision invalidates unsubmitted drafts. An accepted Worker segment may finish after pause. Manual speech and configured scripts retain the operator’s exact words.

| Admin operation | Payload / result |
| --- | --- |
| PATCH /api/avatars/{id} | e.g. `{"interests":["园艺"],"hostMode":"companion"}`. Up to five interests of 40 Unicode characters each. Mode locks during a live session. |
| GET /api/avatars/{id}/host-topics | `{"topics":[],"suggestedInterests":[],"generation":{"state":"idle"}}`. Empty optional lists may serialize as null. Each topic includes id, avatarId, title, key, createdAt, state and angles with id/text. States are ready, active, done and disabled. |
| POST /api/avatars/{id}/host-topics/generate | 202 with avatarId and jobId. Concurrent requests for that avatar share a job. Poll the list for running/completed/failed, added count on success, lastError and optional nextEligibleAt on failure. Early retries receive 429. |
| PATCH /api/host-topics/{id} | e.g. `{"title":"窗台的光","angles":["轮廓","明暗","假想的场景"]}` or `{"state":"disabled"}`. Title up to 80 characters, 3–5 angles of up to 200 each. Returns id. |
| GET /api/live/{id}/host-status | e.g. `{"mode":"companion","state":"waiting","topicTitle":"窗台的光","lastError":"","nextEligibleAt":null}`. States paused/preparing/waiting/speaking/degraded. A scheduled deadline is an RFC3339 timestamp. |
| PATCH /api/live/{id}/host | `{"enabled":true}` resumes. False pauses autonomous hosting. Stop ends the session. |

A batch contains 12 topics. A usable ready reserve below four triggers refill, capped at 36 usable ready topics. An active topic can continue across different angles. An unresolved first segment stays available for receipt reconciliation while its session owns the slot. On terminal cleanup its remaining material retires under the age and count limits. The seven-day history covers at most 200 recent topic keys and 100 autonomous outputs. Generation uses exact normalized matching and character-trigram Jaccard ≥0.75 to reject near repeats. A host segment has 40–120 Unicode characters and 1–3 sentences. The usual pause is 2–5 seconds, increasing to 5–10 on a topic change and 10–20 on a topic change after five quiet minutes. Duration also depends on inference and Worker availability. Degraded hosting retries after 5/15/30/60 seconds with a 60-second cap.

Worker-token-only `GET /sessions/{id}/task-results?after=17` returns e.g. `{"results":[{"seq":18,"taskId":"example","state":"completed","text":"实际口播","completedAt":"2026-11-24T10:00:00Z"}],"nextSeq":18,"truncated":false}`. The current-session outbox holds 256 terminal results. A completed receipt means the complete text reached the local output pipeline. Failed results, pending submissions and collector acknowledgements cannot advance spoken memory. A truncated cursor marks missing pending results unknown. Go correlates registered task IDs, tolerates duplicate receipts and avoids automatically replaying uncertain speech. Delivery to a viewer requires separate evidence.

Admin persona, interests, fixed service rules and server time define the model’s control context. Structured viewer fields, topic material and the latest 12 successful turns are data. Up to 20 processed interactions stay in session memory. Ordinary pending comments expire after 30 seconds; a full 20-item waiting queue skips overflow. A model failure backs off interaction generation across the session for 5, 15, 30, then 60 seconds (capped). During that interval fresh comments return their stable retry IDs. The 30-second expiry still uses first arrival. A skipped event can be processed without generating speech. Model decisions accept only speak/text or skip, with strict shape/length checks. A separate restricted audit checks generated material before use. Invalid or unavailable decisions leave the Worker idle. Generated text has no tool or settings access. Raw viewer text and nicknames are transient. These checks mitigate prompt injection and unverified claims; model judgments can still be wrong.
